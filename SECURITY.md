# Security

You can open a normal public issue for bugs and ideas.

If the problem is about security, email elevatedfriends@gmail.com instead.

Tell us:

- what you found
- how we can repeat it
- what someone could do with it

We will reply as soon as we can.

Reports we care about most:

- a way to read someone's links without their password
- a way to get their key or recovery code
- a way to sign in, or delete an account, without the code we email
